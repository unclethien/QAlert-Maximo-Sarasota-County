Why one text block holds everyone back

The AI reads layout, not place

Similarity compares text, and every request shares one layout. The Maximo Assistant searches fields, so address questions find nothing.

97the real duplicate
93same problem, 6 km away

Search and reports

No field to list requests on a street, the ones that came in by phone, or the urgent ones this week.

Callbacks

The phone number sits inside the text, and Reported by names the integration. Every callback starts with copying.

Upkeep

Pilot scripts pick the address back out of the text. A planner's edit or a new text layout breaks them.

Privacy

Names and phones are copied into free text on the request and its work order, and into whatever reads it, AI included.

Sarasota County MAS AI pilot The data pipeline · 12 / 13

Our proposal: send QAlert's values to Maximo's fields

311 channels

  • 311Connect app
  • 311 web portal
  • Phone to 311
  • Email

QAlert

  • Each value kept on its own

Integration mapping

  • Each value to its Maximo field
  • The text, as today

Maximo request

  • Service address and coordinates
  • Source and reported priority
  • Contact phone and email
  • QAlert request number

Details text kept

County GIS address list

  • Loaded as Maximo service addresses
  1. Map the valuesA mapping change by the integration's owner. No new software, and it helps every request from day one.
  2. Load the address listEach request is matched to a known address on arrival; one that matches nothing is flagged.
  3. AI where rules can'tSuggestions a reviewer accepts, such as reading an unclear description. Not rebuilding values QAlert has.
  4. The Open311 standard for 311 requests keeps lat, long, address_id, email, phone and the name apart from description.

What we need from the County

  1. Who owns the QAlert-to-Maximo integration?The QAlert connector, County middleware, or a Maximo job. It decides how and when.
  2. Which values does the County's QAlert send?We assumed the channel, how a call or email was taken, who entered it, and the resident's phone.
  3. Where should the resident's name live?Only in the text, in a custom field, or as a person record.
  4. Can we load the County address list from GIS?Your attribute list already maps the GIS address columns to Maximo.
  5. How do QAlert's priorities match Maximo's 1 to 4?So Reported Priority means the same thing in both.
  6. Do our lines match your reviewers?85 or more for a likely duplicate, 60 or more for likely related work.

With your answers, we rerun the same checks and show you the difference.
